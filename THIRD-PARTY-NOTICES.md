## Build-time dependencies

These are not vendored and must be supplied by the user:

- **Raspberry Pi Pico SDK** — BSD 3-Clause, Raspberry Pi (Trading) Ltd.
  Required at configure time via `PICO_SDK_PATH`.
- **TinyUSB** — MIT, hapaxx. Ships inside the Pico SDK and provides the USB
  host stack that Pico-PIO-USB plugs into.

## Fonts

### DEC VT220 glyphs — `tools/fonts/DEC-VT220-10x20.bdf`

The default **DEC VT220** face is derived from glyph data dumped from
1986-vintage VT220 ROM firmware (DEC part `23-178E6`).

The MIT grant in `LICENSE` does not purport to relicense the underlying
historical DEC glyph designs. Provenance, the exact upstream source, and the
jurisdictional caveats are documented in full in
`tools/fonts/DEC-Fonts-NOTICE.md`. Read that file before redistributing the
font data or firmware built from it.

### Outline faces (Consolas, Cascadia Mono)

The `Modern` and `Terminal` menu entries are rasterised at build time from
fonts installed on the build machine. **No Microsoft font files are
redistributed in this repository.** Only the resulting baked bitmap tables are
generated locally, into `src/fonts_vt100.c`, which is not committed for those
faces.

### Files in the repository

`src/fonts_vt100.c` and `src/fonts_vt100.h` are generated by
`tools/gen_fonts.py`. The copy committed here was baked from the DEC VT220 BDF
only. Re-running the font bake with outline faces present will regenerate those
files with additional tables; check your font licences before publishing the
result.
